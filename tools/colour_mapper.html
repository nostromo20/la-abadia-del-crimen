Abadia QL colour mapper

What the game shows: the terrain, characters (every sprite the mixer draws: monks, Guillermo, Adso, objects, doors) and panel rows of the day and night palettes, with dithers anywhere. Not shown: the lamp row (the lamp's dark pixels use the terrain pen 3), and the characters / panel rows of palettes 0 and 1 (no sprites or panel are drawn under them). The "Game" view below shows exactly what the build draws (the same rules as tools/colourmodel.py, which the colour checks use).

Pen → QL colour

Second box = optional 2×2 checker dither partner (— = none).

Notes

CPC original colours (hardware inks of the game's palette), same framing.

How to use

1. Pick a palette tab (day, night, parchment, black) and set each pen's QL colour for each pixel source.
   Terrain = tiles and room fills, Characters = monks / Guillermo / Adso / objects / doors drawn by the sprite mixer,
   Panel = the HUD under the play area, Lamp = the dark pixels of Adso's lamp in the dark library.
2. Watch the preview (layout A: play area from line 28, panel from line 188). "Show sources" tints each source.
3. Export JSON and save it as data/colour_mapping.json in the repo (or "Save to repo" when the page was opened with
   python tools/colour_server.py). build_hybrid.sh runs tools/mkpalette.py, which turns it into src/palette_data.s.
